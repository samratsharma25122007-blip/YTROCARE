# 📹 Upload your video here

Drop your video file into this **`uploads/`** folder.

## How it works

1. **Upload** your video into this folder (e.g. `uploads/my-video.mp4`).
   Supported: `.mp4`, `.mov`, `.webm`, `.avi`, `.mkv`, etc.
2. **Tell me** the file name and what kind of website you want, for example:
   - *"I uploaded `demo.mp4` — make a landing page for my product."*
   - *"Use `intro.mov` as the hero background video."*
   - *"Here's `tutorial.mp4`, build a course page around it."*
3. **I build the website** for you in the [`website/`](../website/) folder using
   that video — I'll embed it, generate matching text/sections, and style the page.

## What I can do with the video

- Embed it as a **hero / background video** on the page.
- Build a **video player** page around it (with a title, description, sections).
- If you also give me a **transcript or a description** of what's in the video,
  I can generate matching copy, feature sections, headings, and a call-to-action.

> Note: I can read the file name and any details you give me, but I can't
> "watch" the raw video pixels. The more you tell me about what's in the video
> (or paste a transcript), the better the generated website will match it.

The finished site lives in [`website/`](../website/) — open `website/index.html`
in a browser to view it.
